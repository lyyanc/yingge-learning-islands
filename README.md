# 鶯歌工商・十座學習島

網站：https://lyyanc.github.io/yingge-learning-islands/

參考泰山高中「七座學習島・校園尋寶」（https://samlu1974.github.io/samlu/）的互動形式，為新北市立鶯歌工商重新製作的雲端學習島。九個科班排成三乘三，陶瓷工程科在正中央；夜間上課的進修部在最右邊，以橋梁連到它開設的資訊科與廣告設計科。

## 內容

| 編號 | 島嶼 | 島上的代表物件 |
|---|---|---|
| 1 | 陶瓷工程科（中央） | 陶藝層架、大陶甕，校舍有窯爐煙囪 |
| 2 | 美術工藝科 | 玻璃工藝、木工 |
| 3 | 多媒體設計科 | 螢幕、攝影機 |
| 4 | 廣告設計科 | 廣告看板 |
| 5 | 資訊科 | 電路板、電腦 |
| 6 | 資料處理科 | 長條圖、成長箭頭 |
| 7 | 應用日語科 | 鳥居、櫻花 |
| 8 | 門市服務科 | 小店面、購物車 |
| 9 | 體育班 | 棒球場、拳擊手套 |
| 10 | 進修部（最右邊） | 路燈、書桌、筆電與月亮，校舍窗戶一直亮著燈 |

- 點島嶼、校舍或島名：開啟介紹（介紹文字、三個亮點、標籤、科網頁連結）。
- 十五座橋梁、走動的男女學生與老師，Q 版顏龍源校長在陶瓷島前散步；點校長會顯示校長照片。
- 右上角的小浮島是「鶯歌石」，點了會介紹地名由來。
- 四種場景風格：陶藝風（拉坯機、柴窯、茶席）、科技風、創意風、人文風。
- 校園尋寶：十個發光寶箱、十枚專屬徽章、尋寶雷達；集滿後可輸入姓名下載 PNG 電子證書（證書只在瀏覽器裡產生，不上傳）。
- 日夜切換、拍照模式、全景／近看、旋轉、拖曳、滾輪與雙指縮放；手機版面另外排過。

## 檔案

| 檔案 | 內容 |
|---|---|
| `index.html` | 頁面結構 |
| `style.css` | 樣式（陶土＋青瓷配色） |
| `data.js` | **學校與各科文字、島嶼位置、橋梁、主題**：要改介紹文字只改這個檔 |
| `app.js` | 繪圖與互動 |
| `logo.gif` | 學校校徽（左上角與分頁小圖示） |
| `principal.jpg` | 校長照片（點校長時顯示） |

純靜態網站，不需要安裝或建置。直接用瀏覽器開啟 `index.html` 就能玩（字型從 Google Fonts 載入，離線時會改用系統字型）。

## 文字來源

各科介紹與亮點整理自「115 學年度親職手冊」的各科園地、「115 本校各處室業務 Q&A」（進修部上課時間與班級數），以及學校官網（https://www.ykvs.ntpc.edu.tw/）的科別選單。科網頁連結也取自官網。對外公開前，建議請各科確認一次介紹文字。
